1. PRODUCT OVERVIEW

1.1 Purpose

Budgetrix is a mobile application designed for personal and academic use to help users track, understand, and improve their financial behavior.

The application focuses on simplicity, clarity, and meaningful financial awareness rather than complex automation.

---

1.2 Problem Statement

Most expense tracking applications suffer from:

- High manual data entry effort
- Overly complex and cluttered interfaces
- Lack of meaningful and actionable insights
- Low user retention due to limited long-term value

Users often abandon such applications because they fail to provide ongoing usefulness beyond basic expense logging.

---

1.3 Solution

Budgetrix addresses these challenges by:

- Providing a clean and minimal expense tracking experience
- Implementing a rule-based insight engine to analyze spending behavior
- Presenting insights in simple, human-readable language
- Using SMS detection as a reminder system instead of unreliable automation
- Maintaining a calm, premium user experience

---

1.4 Intended Use

This application is developed strictly for personal use and academic purposes.

It is not intended for commercial deployment or public distribution.

6. INSIGHT ENGINE DESIGN

Budgetrix uses a rule-based insight engine to analyze user spending behavior.

The system:

- Compares current and past spending data
- Detects trends and anomalies
- Generates insights using predefined logic rules

Example:

If current_food_spending > previous_food_spending:
→ "You spent more on food this week"

Insights are generated using templates to ensure clarity and consistency.

Optional:
A lightweight local model may be used in the future to improve phrasing, but not for core decision-making.
